# MOSAIQ User Frontend

This is the Next.js version of the existing MOSAIQ Vite prototype. The current design and static dashboard assets have been copied into this separate project folder so the original Vite prototype remains untouched.

## Local Development

```bash
npm install
npm run dev
```

The app will run at:

```text
http://localhost:3000
```

## Production Build

```bash
npm run build
npm run start
```
